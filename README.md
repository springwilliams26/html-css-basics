# Event Center Website

A fictional concert venue website built with HTML and CSS for a class assignment.  
The site showcases upcoming events, venue information, and interactive features such as a parallax hero section, upcoming shows, and a back-to-top button.

## Features

- Clean **HTML5 structure** (header, nav, section, footer)
- **Responsive design** using Flexbox and Grid
- Smooth “Back to Top” button (JavaScript)
- Contact form with optional email action
- Subtle hover and animation effects for better UX
